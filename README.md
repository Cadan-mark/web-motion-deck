## 一、作品名称

Web Motion Deck —— 基于原生 HTML / CSS / JavaScript 的 Web 视觉交互展示作品

## 二、项目简介

本项目是一个面向课程设计展示、教师评审与在线演示场景开发的原生 Web 视觉交互作品。作品以“动态幻灯片展示”为核心，结合页面转场、微交互、明暗主题切换、动效开关、全屏展示与响应式布局等能力，形成一个可直接通过浏览器访问的静态展示项目。

## 三、项目目标

- 使用原生 HTML、CSS、JavaScript 实现完整前端交互作品
- 展示页面切换、动画编排与视觉反馈能力
- 保证项目无需后端即可部署与访问
- 适配桌面端与移动端浏览环境
- 通过 GitHub 与 GitHub Pages 完成开源展示与成果提交

## 四、功能说明

- 幻灯片式内容展示
- 页面转场与动效呈现
- 微交互反馈
- 明暗主题切换
- 动效开关控制
- 全屏浏览模式
- 响应式布局适配
- 移动端滑动切换支持

## 五、交互方式表

| 交互方式 | 说明 |
| --- | --- |
| 点击切换 | 通过按钮或导航控件切换展示内容 |
| 键盘操作 | 使用方向键或指定按键浏览页面内容 |
| 主题切换 | 在亮色与暗色主题之间切换 |
| 动效开关 | 开启或关闭页面中的动态效果 |
| 全屏展示 | 进入全屏模式进行沉浸式浏览 |
| 移动端滑动 | 在触屏设备上通过左右滑动切换内容 |

## 六、技术实现

- **HTML**：负责页面语义结构与展示内容组织
- **CSS**：负责布局、配色、转场动画、响应式适配与主题样式
- **JavaScript**：负责页面切换逻辑、事件绑定、状态切换与交互控制
- **GitHub Pages**：负责静态站点在线部署与公开展示

## 七、实现过程

1. 明确作品定位与展示目标
2. 设计页面结构与幻灯片式内容组织方式
3. 编写样式系统，实现基础布局与视觉效果
4. 使用 JavaScript 实现交互逻辑与状态控制
5. 增加主题切换、动效开关、全屏与移动端适配能力
6. 整理仓库文件，补充开源说明、许可证与部署文档
7. 通过 GitHub Pages 发布在线演示页面

## 八、技术难点

- 在原生技术栈下组织清晰的交互逻辑
- 在保证视觉表现的同时兼顾性能与可维护性
- 兼容桌面端与移动端的不同交互方式
- 让主题切换、动效控制与全屏功能彼此协同工作
- 通过静态部署方式完整呈现作品交互效果

## 九、项目亮点

- 采用原生前端技术实现，无需额外框架依赖
- 同时具备展示性、交互性与可部署性
- 适合作为课程设计、作品集或课堂答辩展示项目
- 可直接托管在 GitHub Pages，便于教师与评委在线查看

## 十、运行说明
